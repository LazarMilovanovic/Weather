# 🌤️Weather App
A responsive weather web application built with HTML, CSS, and JavaScript, powered by a weather API to deliver real-time meteorological data for any city or country in the world. The app provides an hourly forecast for the next 24 hours, a 7-day outlook, and a rich set of additional weather details — all in one place.

### API Link
https://open-meteo.com/
